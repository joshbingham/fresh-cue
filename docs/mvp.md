# FreshCue MVP

## Core Workflow

1. Add a food item.
2. Record its quantity, expiry date and storage location.
3. View items ordered by urgency.
4. Search and filter the inventory.
5. Edit or remove items when they are used, wasted or no longer needed.

## MVP Features

- Add a food item manually
- Edit an existing item
- Delete an item
- Record quantity
- Record expiry date
- Choose a storage location:
  - Fridge
  - Freezer
  - Cupboard
- Show items that need using soon
- Search inventory by item name
- Filter inventory by storage location
- Display basic empty, loading and error states
